## 📥 Pobierz

Pobierz najnowszą wersję z zakładki **Releases** lub ze strony GitHub Pages.

## 📱 Wymagania

- Android 7.0 lub nowszy
- Około 10 MB wolnego miejsca

## 📥❓️ Jak Pobrać?

--🟢 ANDROID 🟢--
1. Wejdź w Zakładkę **"Releases"**
2. Pobierz najnowszy Plik APK
3. Zainstaluj Aplikacje
--🟦 WINDOWS 🟦--
1. Pobierz BlueStacks (wirtualizacja musi być włączona w biosie)
2. Wejdź w Zakładkę **"Releases"**
3. Pobierz najnowszy plik APK
4. Odpal plik APK i wybierz Bluestacks
